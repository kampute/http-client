    Definition

    Defines a content format that converts between HTTP content and .NET objects.
    public interface IHttpContentFormatter
    Implemented by
    • HttpContentFormatter
    • FormUrlEncodedFormatter
    • XmlFormatter

    Remarks

    A formatter has a reading side and a writing side. The reading side turns response content into objects: GetReadableMediaTypes(Type) lists the media types the formatter can read into a model type, which HttpRestClient uses to build the Accept header, and CanRead(string, Type) and ReadAsync(HttpContent, Type, CancellationToken) select the formatter for a response and read its content. The writing side turns objects into request content: GetWritableMediaTypes(Type) and CanWrite(string, Type) select the formatter for a payload, and Write(object, string) creates the content.

    A formatter can support one side only. A receive-only formatter returns no writable media types and never accepts a payload, and a send-only formatter returns no readable media types and never accepts a response.

    Media types are case-insensitive, so implementations compare them ignoring case. Implementations are expected to be thread-safe, because a formatter registered with a client is shared by all its requests.
