    Definition

    Represents the content formatters of an HttpRestClient, in the order they were added.
    public sealed class HttpContentFormatterCollection : ICollection<IHttpContentFormatter>, IReadOnlyCollection<IHttpContentFormatter>

    Remarks

    This collection holds the content formatters of an HttpRestClient. It selects the formatter that reads a response with GetReaderFor(string, Type), the formatter that writes a request payload with GetWriterFor(string, Type), and the media types of the Accept header with GetAcceptableMediaTypes(Type). When several formatters match, the one added first is used.

    Media types that differ only in case are treated as the same media type. A formatter that is found is cached for later lookups of the same media type and type; a failed lookup is not cached.

    GetAcceptableMediaTypes(Type)

    Retrieves the media types that the formatters in the collection can read into a specified model type.
    public IEnumerable<string> GetAcceptableMediaTypes(Type modelType)

    Parameters

    modelType Type
    The type of the object to read, or null if any content is acceptable.

    Returns

    IEnumerable<string>
    The media types that can be read into modelType, in the order of the formatters, without duplicates.

    Remarks

    If modelType is null, this method returns only "*/*", signifying that all media types are acceptable.

    Send-only formatters contribute no media types.

    GetAcceptableMediaTypes(Type, Type)

    Retrieves the media types that the formatters in the collection can read into a specified model type or error type.
    public IEnumerable<string> GetAcceptableMediaTypes(Type modelType, Type errorType)

    Parameters

    modelType Type
    The type of the object to read, or null if any content is acceptable.
    errorType Type
    The type of the error object to read, or null if errors are not read.

    Returns

    IEnumerable<string>
    The media types that can be read into either type, model type first, without duplicates.

    Remarks

    If errorType is null, the result is the same as for GetAcceptableMediaTypes(Type).

    If modelType is null and errorType is provided, the result includes the media types that can be read into errorType, followed by "*/*" to indicate that any content is acceptable for the model.
