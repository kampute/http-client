    Remarks

    This formatter is send-only: it writes payloads that implement IEnumerable<T> of KeyValuePair<TKey, TValue> with string keys and values as application/x-www-form-urlencoded content, and does not read responses. The form helpers of HttpRestClientFormExtensions use it.
