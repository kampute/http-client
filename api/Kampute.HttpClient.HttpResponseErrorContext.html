    Waits as the retry session of the source decides, and returns a clone of the request to retry, or a decision not to retry.
    public Task<HttpErrorHandlerResult> ScheduleRetryAsync(object source, Func<HttpResponseErrorContext, IRetrySession> sessionFactory, CancellationToken cancellationToken = default)

    Parameters

    source object
    The component that handles this kind of failure and counts its retries, typically the IHttpErrorHandler that handles the response.
    sessionFactory Func<HttpResponseErrorContext, IRetrySession>
    A function that creates the retry session of the source from this context, or returns null if the source does not retry.
    cancellationToken CancellationToken optional
    A token that can be used to cancel the operation.

    Returns

    Task<HttpErrorHandlerResult>
    A task that resolves, after the wait, to a decision to retry with a clone of the request, or to HttpErrorHandlerResult.NoRetry.

    Exceptions

    ArgumentNullException
    Thrown if source or sessionFactory is null.

    Remarks

    Each source has its own retry session for a call, as described for HttpRequestErrorContext.ScheduleRetryAsync(object, Func<HttpRequestErrorContext, IRetrySession>, CancellationToken).
