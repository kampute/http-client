    Remarks

    The formatter also reads any media type with the +json structured syntax suffix, which RFC 6839 permits for media types whose representation follows application/json, such as application/vnd.example+json, but does not advertise it. It writes application/json only.

    The client reads a response with the first formatter in HttpRestClient.ContentFormatters that can read it, so a formatter for a specific +json media type takes over that type only when it is added before this one.

    Register the formatter with UseNewtonsoftJson(this HttpRestClient, JsonSerializerSettings). Its Settings apply both to the responses it reads and to the payloads it writes. Change them before the client sends requests, because a registered formatter is shared by all requests of the client.
