    Retries failed HTTP requests as a retry strategy decides.
    public class HttpRetryPolicy : IHttpRetryPolicy

    Remarks

    Create a policy from any IRetryStrategy with ToHttpRetryPolicy(this IRetryStrategy). Each call that fails gets its own RetrySession, so the strategy, and the policy, can be shared by any number of requests and clients.

    To choose the strategy or the session from the failure, use Dynamic(Func<HttpRequestErrorContext, IRetryStrategy>) or Dynamic(Func<HttpRequestErrorContext, IRetrySession>).

    Examples

    This policy retries a request up to five times after connection failures, with delays that grow with the Fibonacci sequence from one second:
    client.RetryPolicy = RetryStrategies.Fibonacci(TimeSpan.FromSeconds(1)).WithMaxRetries(5).ToHttpRetryPolicy();
