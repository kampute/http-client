Kampute.HttpClient.Xml Namespace

This namespace provides support for XML serialization in HTTP requests and responses, specifically for handling application/xml content types using the XmlSerializer.

Classes

HttpRestClientXmlExtensionsProvides extension methods for HttpRestClient to support XML-based HTTP operations.
XmlContentRepresents HTTP content based on XML serialized from an object.
XmlContentDeserializerProvides functionality for deserializing XML content from HTTP responses into objects.
