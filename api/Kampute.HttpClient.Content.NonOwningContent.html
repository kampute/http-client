    NonOwningContent Class

    Namespace
    Kampute.HttpClient.Content
    Assembly
    • Kampute.HttpClient.dll

    Definition

    Represents an HTTP content that sends another content unchanged, without taking ownership of it.
    public sealed class NonOwningContent : HttpContentDecorator
    Inheritance
    • object
    • HttpContent
    • HttpContentDecorator
    • NonOwningContent

    Remarks

    This class passes the headers and body of the original content through unchanged. Disposing an instance of this class does not dispose the original content, so the original content stays usable and its owner remains responsible for disposing it.

    Use this class when a component that disposes the content it receives must not end the life of the original content. For example, HttpClient on .NET Framework disposes the content of every request it sends, which prevents the same content from being sent again. Sending a NonOwningContent instead keeps the original content available for another attempt.

    The original content can be sent again only if it is reusable. For example, a StreamContent over a stream that cannot be read twice remains non-reusable when wrapped.
