    Remarks

    When a request receives an error response, HttpRestClient asks the handlers in HttpRestClient.ErrorHandlers whose CanHandle(HttpStatusCode) accepts the status code, in order, until one of them returns a request to retry. If none does, the error is thrown as an HttpResponseException. A handler can retry a clone of the failed request or a request it builds, for example one with new credentials after a '401 Unauthorized' response.

    A handler is shared by all the requests of the clients it is added to, so implementations must be thread-safe.
